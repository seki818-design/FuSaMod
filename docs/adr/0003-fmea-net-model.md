# ADR-0003: FMEA をネットの射影として扱う

- 状態: 採用(G0 でレビュー)
- 決定: 構造・機能・エラーの 3 ネットを正本とし、FMEA シートは注目要素ごとの射影として導出する。故障ノードは階層をまたいで 1 つの実体を共有する(下位の FM=注目要素の FC、注目要素の FM=上位の FE)。
- 理由: 上位/下位 FMEA の不整合を構造的に防ぎ、変更影響を伝搬できる。
- 保存: ハイブリッド。意図機能・安全機構・ASIL は SysML メタデータで注釈し、ネット本体は構造化データ。いずれもテキストでエクスポートする(P0 で MBSE 専門家が確認)。
