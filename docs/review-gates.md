# レビューゲート

各フェーズ終了時に、外部レビューア 2 名が書面でレビューする。指摘は Issue 化し、重大度で受入を判断する。

| ゲート | ISO 26262 専門家 | MBSE 専門家 |
|---|---|---|
| G0(P0 終了) | FMEA ネット連携ルール、ASIL 分解ルール表、ペア属性、AP/RPN の扱い、ツール信頼性(ISO 26262-8)の論点 | SysML v2 方式(ADR-0002)、メタデータ設計、階層自動生成ルール |
| G1(P1) | — | モデル読込/表示の SysML 準拠度 |
| G2(P2) | 分析フロー(FMEA/FTA/HARA)、デコンポジション検証、FMEA-MSR | モデルとネットの対応、トレーサビリティ |
| G3(P3) | AI 提案の妥当性(抽出レビュー)、承認フロー | — |
| G4(P4) | 整合判定の安全上の妥当性 | 階層ルール、Puzzle View の意味 |
| G5(P5) | 総合 | 総合 |
| G6(P6) | SCDL 変換の妥当性 | SCDL 変換の妥当性 |

## 現時点でレビューに出す論点(G0)

3. 重大度を最上位 FE に付け下位へ継承する方式
4. 意図機能と安全機構が同一要素にある場合の扱い(現状は FFI 根拠を求める警告)
5. ガイドワード(`guidewords.ts`)の初期セット
